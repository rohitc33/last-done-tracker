# Last Done Tracker

A single-file, mobile-friendly page for tracking when you last did things.

- Add items with the box at the top.
- **Press and hold** an item (~0.6s) to set its "last done" to now. A toast lets you undo.
- Tap **⋯** to rename, set a specific date/time, or delete an item.
- Tap the sort button to cycle Oldest first / Newest first / A–Z.

Everything is stored in the browser's `localStorage` — no server, no network.
Just open `index.html` (or host it anywhere static, e.g. GitHub Pages) and add it to your home screen.
